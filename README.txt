我的故事词汇学习器：公开框架

这个版本只提供学习器框架和公开示例，不内置个人故事或私人词汇。

使用方式：
1. 用 AI 按 DATA_PACK_FORMAT.md 生成一个 JSON 词汇包。
2. 用 HTTPS 打开本 PWA，在“词海”页面选择 JSON。
3. 选择“合并导入”加入新故事，或选择“替换当前数据”建立一套新词库。
4. 可以随时“导出备份”，把当前词汇包保存到本地。

数据和进度：
- 词汇包保存在当前浏览器的 localStorage，不会自动上传到 GitHub。
- 浏览器清除站点数据后，需重新导入 JSON；建议定期导出备份。
- GitHub 公开仓库只放框架和示例数据，个人内容通过本地导入使用。

中文功能说明：

这是一个可导入 JSON 词汇包的故事词汇学习 PWA 框架，支持词海浏览、回忆练习、Quiz、合并或替换词库及本地备份。
